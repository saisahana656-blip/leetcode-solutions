# LeetCode Solutions Portfolio

A collection of LeetCode practice solutions organized by topic. Each problem should include a solution, a short explanation, test cases, and a record of the submission result.

## Repository structure

- `arrays-strings/` — array and string problems
- `basic-algorithms/` — searching, sorting, and algorithm fundamentals
- `stacks/` — stack problems
- `linked-lists/` — linked-list problems
- `docs/authentication.md` — explanation of authentication concepts and request flow
- `PROGRESS.md` — practice tracker

## How to add a solution

1. Save the solution in the matching topic folder.
2. Add a Markdown note describing the problem, approach, complexity, and test cases.
3. Test locally and record the result.
4. Submit the solution on LeetCode and capture an Accepted screenshot if required by your assignment.
5. Update `PROGRESS.md` and commit your changes.

## Authentication scope

This repository is a LeetCode practice portfolio, not an authentication service. The authentication document explains the sign-in and token concepts relevant to using web services and GitHub. It does not claim that this repository implements LeetCode login, issues tokens, or validates API requests.

## Safety

Never commit passwords, session cookies, personal access tokens, API keys, or other secrets. Use the service's official sign-in flow and store development secrets outside source control.
